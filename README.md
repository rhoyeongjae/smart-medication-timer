# 💊 약 복용 관리 서비스

> 사용자의 건강한 일상을 위한 맞춤형 복약 관리 및 복용 체크 웹 서비스입니다.

## 프로젝트 소개

약 복용 시간을 잊거나 복용 여부를 헷갈리는 문제를 해결하기 위해 제작한 웹 서비스입니다.

사용자가 복용할 약과 시간을 등록하고, 매일의 복용 현황을 확인하며 복용 여부를 기록할 수 있습니다.

---

## 구현 완료 기능

### 1. 복약 관리

- 약 이름 및 복용 시간 등록
- 등록된 약 목록 조회
- 등록된 약 삭제
- 오늘의 전체 복약 일정 확인

### 2. 복용 체크

- 복용 완료 버튼을 통한 복용 여부 기록
- 복용 완료 상태 표시
- 복용 완료 및 미완료 개수 확인
- MySQL 데이터베이스에 복용 기록 저장

### 3. 알림 기능

- 브라우저 알림 권한 요청
- 10초 뒤 테스트 알림 제공
- 브라우저 알림을 통한 복약 안내

### 4. 화면 구성

- 오늘 날짜 표시
- 전체 복약 개수 표시
- 복용 완료 및 남은 약 개수 표시
- 약 목록 및 복용 상태 표시
- 약 추가 및 삭제 버튼

---

## 개발 환경

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express
- Database: MySQL
